# プロダクト寿命DB パイロット

2025年1月〜2026年10月15日に東証グロースへ新規上場した企業のうち、インターネットプロダクトを運営する企業について、各プロダクトが「リリースから何年続いているか」を集計したダッシュボードです。

**公開ページ：** https://taro-yoshioka.github.io/product-lifespan-db/

## 見られること

- **サマリー**：対象企業数、プロダクト数、稼働中・終了・状況不明の件数、10年生存率
- **プロダクトの生存曲線**：リリースから何ヶ月後にまだ提供されているかの割合（カプラン・マイヤー推定）
- **リリース年別のプロダクト数と現在の状態**
- **5年以上続くプロダクトは伸びているか**：開示KPI（ARR・会員数・契約数など）による判定
- **終了・統合・譲渡したプロダクト**：寿命が確定した全件
- **プロダクト一覧・対象企業一覧**：検索・並べ替えができる表

## データ

| ファイル | 内容 |
| --- | --- |
| [`products.csv`](products.csv) | プロダクト台帳（146件） |
| [`companies.csv`](companies.csv) | 対象期間に上場した60社と、対象・境界・対象外の区分 |

### 集め方

有価証券報告書と新規上場申請のための有価証券報告書（Iの部）の沿革、JPXの新規上場資料、各社の公式発表から手作業で集めました。状態は2026年10月時点のものです。

- **対象**：インターネットプロダクトが主な事業の企業（25社）
- **境界**：判断が分かれる企業（3社）。集計では別扱いにしています。
- **対象外**：インターネットプロダクトが主な事業ではない企業（32社）

### `products.csv` の主な列

| 列 | 意味 |
| --- | --- |
| `code` / `company` / `listed` | 証券コード・企業名・上場日 |
| `product` / `type` | プロダクト名・区分（BtoB など） |
| `launch` / `launch_year` | リリース年月・リリース年 |
| `status` | 稼働中／終了／統合／譲渡／販売終了／不明 |
| `end` / `end_type` / `successor` | 終了年月・終了の種類・統合先や譲渡先 |
| `months` | 寿命（月）。稼働中は2026年10月までの月数 |
| `event` | 1＝寿命が確定（終了・統合・譲渡）、0＝打ち切り |
| `confidence` | 確度。高＝沿革に明記／中＝沿革と公式サイト等から推定／低＝沿革に以後の記載がなく現状は未確認 |
| `growth` / `growth_evidence` / `growth_source` | 5年以上続くプロダクトの成長判定と、その根拠・出典 |
| `source` / `note` | 出典URL・備考 |

## 集計の考え方

- 生存率はカプラン・マイヤー法で推定しています。稼働中のプロダクトは2026年10月時点で観測を打ち切った（センサー）ものとして扱います。
- 状況が「不明」のプロダクトは扱いで結果が変わるため、生存曲線では2本示しています。
  - 実線：不明を除いて推定
  - 点線：不明を稼働中とみなして推定
- 「終了」には、サービスの完全な終了だけでなく、別プロダクトへの統合や事業譲渡も含みます。

## 注意

- パイロット版です。母集団が小さく、平均寿命（生存率50%）はこの母集団ではまだ観測できていません。
- 開示資料に載っていないプロダクトや、沿革に書かれていない終了は漏れている可能性があります。
- 投資判断を目的としたものではありません。

## ローカルで見る

CSVを読み込むため、ファイルを直接開くのではなくローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8765
```

起動後、http://localhost:8765/ を開きます。

## 構成

- `index.html`：ダッシュボード本体。グラフ描画に [d3 v7](https://d3js.org/)（cdnjs から読み込み）を使っています。
- ビルドは不要です。GitHub Pages で `main` ブランチのルートをそのまま公開しています。
